# X scout roster — template

Source list for the quote-post scouting step. Scouting only — the competitor
screen and the quote-fit test still decide what becomes a quote post.

Confidence tags: `v` = handle verified by a human or a live scout. `tc` = to
confirm on first scout. Confirm a `tc` handle the first time it gets scouted
and flip it in the same commit. A wrong handle yields no results — never
guess around one.
